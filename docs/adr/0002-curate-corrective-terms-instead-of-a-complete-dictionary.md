# 策展纠错术语而非构建完整词典

发布词表只收录具有跨作品纠错价值、在正式日文页面中确有用例且能够确定单一准确通行译法的最小完整表达，不追求词典式穷举；每个正式源词至少具有两个不同日本商业动画作品的正式日文页面用例，同一作品的官网、转载和 STAFF 页面重复出现只计一个作品，至少一个用例支持具体行业含义，另一个证明跨作品复用，找不到第二部作品用例时保留为候选。源词可以包含汉字、假名或拉丁字母，但不自动生成变体，目标词不得包含并列候选、解释或非固定括注。每条正式术语必须记录收录价值判断：纠错型用于修正误译、漏译或语义混淆，一致型用于稳定跨页面或跨结果的不一致译法，保护型用于防止完整行业表达被拆分或泛化；实际机器翻译观测有则作为高优先级旁证，但不作为逐条准入硬门槛，没有任何一种收录价值的普通领域词不得发布。短词与重叠词必须通过非动漫含义、子串冲突和负面样例审查。正式首版以 80 至 120 条通过全部准入检查的高置信术语作为硬性送审窗口：不足 80 条不发布，超过 120 条时将低优先级条目延期到后续版本，且不得为达到数量降低准入标准；自动策展默认在首个同时满足分类覆盖、站点作用域、页面审查和其他发布门槛的 80 条处停止，只有补齐类别、作用域或替换风险条目时才继续增加，剩余高质量候选留给后续版本。数量达标只允许进入发布审查，不替代覆盖、站点和上游维护者审核门槛。
