# 使用来源约束的自动策展

正式首版扩充采用来源约束的自动策展，而不要求不懂日语的仓库所有者逐条进行形式化人工判断。系统可以自动发现、研究并接受术语，但日文含义和中文译法必须由可定位的正式页面支持，提议与复核步骤必须隔离上下文并结论一致，结构检查和风险审查必须通过；复核步骤从原始来源主动寻找反例、竞争译法和来源依赖，可以与提议步骤使用同一模型但不继承其理由或置信度，不通过第三模型投票覆盖分歧。自动化采用 Agent 策展流程：Agent 负责联网研究和语义判断，仓库程序负责页面文本提取、去重、结构校验、摘录检查、覆盖统计、CSV 导出和交付检查，各阶段结果写入结构化文件以支持中断恢复；仓库不内置模型 API 应用、不保存模型密钥，也不绑定供应商 SDK。模型记忆与机器翻译不能作为定稿来源，任何证据冲突、步骤分歧或未解决风险都使条目保留为候选，最终发布仍由 `immersive-translate/terms` 上游 PR review 决定。
