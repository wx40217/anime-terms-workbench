# 要求双向证据并将旁证与发布格式分离

每个已接受术语必须同时具有日文行业含义证据和简体中文用法证据，来源按权威性分级，社区内容、搜索结果和机器翻译只能发现线索；竞争译法还需比较至少两个相互独立的中文正式来源，并在准确译法中选择中国大陆正式动漫语境里更通行的表达。发布数据在交付仓库中继续使用 `glossaries/anime_zh-CN.csv` 的三列格式，结构化旁证保存在工作台的 `evidence/anime_zh-CN.json`，记录候选状态、来源标题与发布机构、来源类型、链接或书目引用、核对日期、证据摘要和取舍理由，并通过交付前检查保证每个 CSV 条目与唯一一条 `accepted` 记录双向一致。
