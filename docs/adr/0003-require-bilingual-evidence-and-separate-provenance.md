# 要求双向证据并将旁证与发布格式分离

每个已接受术语必须同时具有日文行业含义证据和中文通行性证据，来源按发布者身份和编辑责任分层：动画或版权方官网、正版授权平台、出版社、制作与发行公司页面，以及有明确编辑责任的国家级媒体、行业媒体和专业资料库可以作为定稿来源；Wikipedia、百度百科、萌娘百科等社区可编辑百科，论坛、社交媒体、用户投稿、搜索摘要、聚合转载、机器翻译和模型知识只能发现线索或补充判断，来源归属无法确认时默认不能定稿。简体中文定稿证据还必须来自人工编辑中文来源：官方人工发布或维护的中文页面、正版授权平台中文资料和有明确中文编辑责任的内容可以定稿；页面由 WOVN 等自动本地化服务生成且无法确认人工覆盖时，即使位于官方域名也只能补充判断，日文原站的日文侧权威性不受影响。每条正式术语至少需要两个相互独立的人工编辑中文定稿来源，同一发布者、平台或转载链只计一次；两个来源采用相同译法时支持其通行性，采用不同译法时自动进入竞争译法审查，并在准确译法中选择中国大陆正式动漫语境里更通行的表达，找不到第二个独立来源时保留为候选。每个定稿证据项必须保存支持具体判断所需的有限原文字面摘录，日文摘录包含字面源词，中文摘录包含定稿译法，程序检查精确出现关系；摘录不得由模型翻译、改写或补全，也不得扩展为完整网页或长篇转载，证据摘要不能替代原文摘录。正式页面只有图片文字时可以保存明确标记的图像证据转录，但页面和图片必须可稳定定位，两个隔离 OCR 或视觉识别步骤必须对关键字面文本逐字一致；任一字符分歧、图片模糊或定位不稳定时只能作为发现线索，社交媒体图片、搜索缩略图和转载截图不能成为定稿证据，有同等质量的机器可读文本时优先使用文本来源。发布数据在交付仓库中继续使用 `glossaries/anime_zh-CN.csv` 的三列格式，结构化旁证保存在工作台的 `evidence/anime_zh-CN.json`，记录候选状态、来源标题与发布机构、来源类型、链接或书目引用、核对日期、证据摘录或图像转录、证据摘要和取舍理由，并通过交付前检查保证每个 CSV 条目与唯一一条 `accepted` 记录双向一致。
