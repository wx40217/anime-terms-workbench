# 发布 CSV 与旁证一致性契约

统一交付就绪命令将发布 CSV 解析为结构化数据，再与旁证记录进行严格双向比较。诊断先报告结构错误，再聚合仍可可靠定位的重复和一致性错误。CSV 语法损坏、表头不可解释或旁证准入无效时，不执行依赖相应数据的比较，避免级联误报。

## CSV 结构

- 表头必须且只能是 `source,target,tgt_lng`，顺序不可改变。
- 每个数据行必须且只能包含三列。
- `source` 和 `target` 必须是非空字符串，`tgt_lng` 必须为 `zh-CN`。
- 支持使用双引号包围字段、字段内的分隔逗号、以 `""` 表示的字面双引号，以及 LF 或 CRLF 换行。
- CSV 末尾可以有一个换行；空白字符不会被自动裁剪。

## 双向一致性

- 每个 `accepted` 旁证记录必须对应 CSV 中唯一一行，`source` 和 `target` 都须逐字相同。
- 每个 CSV 数据行必须对应唯一的 `accepted` 旁证记录。
- `candidate` 记录不得进入 CSV。
- 相同 `source` 的重复 CSV 行、互相冲突的 CSV 译法，以及重复的 `accepted` 旁证记录都会阻塞交付。
- 比较不执行大小写转换、空白裁剪或 Unicode 归一化。任何差异都视为交付数据被改动。

诊断使用稳定的输入顺序，并标出 `csv.rows[n]` 或 `evidence.records[n]`。修正后应重新运行统一命令，直到返回零状态。
