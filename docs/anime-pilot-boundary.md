# anime 不公开试点边界

统一交付就绪命令对候选元数据和可选公共索引执行以下自动检查：

- 元数据文件名必须为 `anime.json`，`id` 和 `glossary` 必须为 `anime`。
- `langs` 必须包含且只能包含一次 `zh-CN`，不得包含 `auto` 或其他目标语言。
- `i18ns.zh-CN` 必须提供非空的 `name` 和 `description`。
- `matches` 必须包含 2 至 3 个互不重复、带具体域名主机的站点匹配规则；`*`、`*://*/*`、`https://*/*` 等无具体主机的规则视为全局匹配。
- 提供公共索引时，索引必须是数组且不得包含 `anime`。省略索引表示术语库仍处于不公开试点。

检查器只确认规则明确且限制了自动生效范围，不判断候选站点是否适合加入白名单。站点适用性和来源质量仍须分别进行人工研究。
